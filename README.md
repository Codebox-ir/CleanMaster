# CleanMaster

A lightweight tool to clean junk files and improve Windows performance safely.

[[Website](http://cleanmaster.codebox.ir)]

## 🚀 Overview

CleanMaster is a fast, portable, and reliable utility designed to remove unnecessary files from Windows systems.  
It helps reclaim storage space and improves responsiveness without using heavy cleaning software.

## ✨ Features

- Clean Windows cache & logs  
- Clear browser caches (Chrome / Edge / Firefox – where accessible)  
- Clean system temp safely  
- Clear Windows update cache  
- Clean DNS cache  
- Empty Recycle Bin (PowerShell-based for reliability)  
- Fast, safe, and portable  
- No installation required  

## 💻 Supported Systems

- Windows 10 (64‑bit)  
- Windows 11  
- May also work on Windows 8 / 8.1 (not fully tested)

## 🧠 Why CleanMaster?

Unlike heavy system cleaners, CleanMaster is built for speed, clarity, and safety.  
It performs essential cleanups without touching sensitive system components or causing instability.

## 🛠 Tech / Approach

- Lightweight CLI-based tool  
- Designed for stability (Temp cleaning disabled to avoid issues in EXE runtimes)  
- Uses Windows-native commands + PowerShell for reliable cleanup  
- Zero external dependencies
